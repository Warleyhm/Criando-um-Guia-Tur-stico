## ⚠️ Configuração da API

Este projeto utiliza a API da Groq para gerar respostas do guia turístico.

Para executar o notebook, é necessário adicionar sua própria **API Key**.

Antes de rodar o código, execute a célula abaixo e substitua pela sua chave:

```python
import os
os.environ["GROQ_API_KEY"] = "COLOQUE_SUA_CHAVE_AQUI"
```

Depois execute o restante do notebook normalmente.

🔒 A chave não foi incluída no repositório por motivos de segurança.
